ИНСТРУКЦИЯ ПО УСТАНОВКЕ КАЛЬКУЛЯТОРА «Devis Rénovation»
НА ДРУГОЙ КОМПЬЮТЕР (Windows 10/11)
============================================================

ШАГ 1. СОБОРКА УСТАНОВОЧНОГО ФАЙЛА (на вашем ПК, один раз)
------------------------------------------------------------
1. Убедитесь, что на компьютере установлен Node.js
   (если нет — скачайте с https://nodejs.org, версия LTS).
2. Откройте папку проекта (где лежит main.js) в терминале:
   - в проводнике в адресной строке напишите cmd и нажмите Enter,
     либо откройте терминал в этой папке.
3. Выполните команды по очереди:
      npm install
      npm run dist
4. Дождитесь окончания. В папке release появится файл:
      Setup-Devis-Renovation-1.0.1.exe
   Это готовый установщик — на другой ПК Node.js НЕ нужен.

ШАГ 2. ПЕРЕНОС НА ДРУГОЙ ПК
------------------------------------------------------------
Скопируйте файл Setup-Devis-Renovation-1.0.1.exe на флешку
или отправьте его по почте/мессенджеру.

ШАГ 3. УСТАНОВКА (на другом ПК)
------------------------------------------------------------
1. Запустите Setup-Devis-Renovation-1.0.1.exe.
2. Следуйте мастеру установки:
   - принимайте лицензию,
   - при желании выберите папку установки (по умолчанию —
     в профиле пользователя),
   - галочки «Ярлык на рабочем столе» и «В меню «Пуск»»
     рекомендуется оставить.
3. Нажмите «Установить», затем «Готово».

ШАГ 4. ЗАПУСК
------------------------------------------------------------
Запустите калькулятор ярлыком «Devis Rénovation»
на рабочем столе или из меню «Пуск».

ПРИМЕЧАНИЯ
------------------------------------------------------------
- Данные хранятся локально на ПК пользователя
  (каталог работ, компания, настройки, архив смет).
- При первом запуске калькулятор наполнен демо-каталогом
  работ — его можно отредактировать или заменить
  импортом из Excel (в меню приложения).
- Антивирус может спросить разрешение при первом запуске —
  это стандартное поведение для программ без цифровой подписи.
